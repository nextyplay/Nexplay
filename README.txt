# NEXPLAY

Portal de jogos demonstrativo, responsivo e em português.

## Como abrir
Extraia o ZIP e abra `index.html` no navegador.

## Publicar
O site é estático: pode ser publicado em um serviço de hospedagem de sites estáticos. Não precisa de chave de API nem cadastro de jogadores. Peça ao responsável para acompanhar a criação de contas e a publicação.

## Recursos
- Design responsivo para celular e computador
- Busca de jogos
- Teste de reflexo
- Memória de cores
- Clique Turbo
- Recorde de reflexo salvo no navegador (localStorage)

Este é um projeto independente para aprendizado. Não inclui compras, anúncios ou coleta de dados.
